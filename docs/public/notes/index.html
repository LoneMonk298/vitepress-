从 Markdown 导入

粘贴 AI 生成的 Markdown 大纲，自动转成思维导图。
第一个节点作为根，缩进自动识别。

支持：
• ## / ### / #### 层级
• - / * / + 列表、1. 有序列表
• [[空格]] 缩进嵌套
• Markdown 表格：自动拆成「行节点 → 各列（列名：值）」
• **粗体**、*斜体*、~~删除线~~、$公式$
• [文字](https://...) 外链
• [[目标笔记名]] 跳到另一篇笔记
• [文字](note:目标笔记名) 同上（可改显示文字）
• ![说明](图片地址) 插入图片（可写 =300x200 指定尺寸）
• 也可直接把图片文件拖进画布，或截图后 Ctrl+V 粘贴成图片节点
或
支持 XMind 2024 及以前版本（content.json）。
图片全部内嵌显示（base64）；多画布 → 多篇笔记。

编辑节点内容

支持 $公式$、![图片](链接)、[[笔记名]]、Markdown 表格、**粗体**、*斜体*、~~删除线~~。
表格直接粘贴 Markdown 文本即可（第一行表头，第二行 |---|---|），不用再截图；预览区就是节点里显示的效果。

输入内容后自动预览

服务器同步

所有笔记数据同步到自有服务器，支持大文件（无 100KB 限制）。
适合多设备备份：手机、电脑、平板数据互通。
注意：截图存在本地图片库，同步只传文字结构，换设备后原截图位置会显示空白占位。

统计与复习进度

各笔记复习进度一目了然：已完成 表示演示模式看到最后一张；复习到 x/y 表示下次可继续。

合并笔记

勾选要合并的笔记，合并后每篇笔记的中心主题成为总图下的一个并列分支（章节）。
原笔记保持不变；合并后可用 [[#关键词]] 在总图内互跳。

导出文本大纲（给 AI 重新梳理）

按缩进列表输出节点原文，保留 **粗体**、$公式$、#标签、[[链接]] 语法；base64 图片折叠成 [图片]，便于整段粘给 AI 让它重排层级。
