# 笔记导图 /notes/ — 实现说明与路线图

> 考研复习用的 Markdown 思维导图笔记工具，基于 MindElixir，已部署在 `https://blog.lonemonk.xyz/notes/`
> 入口：数学考点取舍表 → 右上角「笔记导图」按钮

---

## 一、Markdown 语法速查

所有语法写在节点文本里，保存后保留原文，编辑后不丢失。

### 结构

```
## 标题节点              → 解析时第一个节点作根
- 列表项                → 普通子节点
  - 缩进嵌套            → 更深层级（自动兼容 2/4 空格）
```

### 内容增强

```
$(-1)^{i+j}$            → LaTeX 行内公式（KaTeX 渲染）
$$\begin{pmatrix}A&B\end{pmatrix}$$  → LaTeX 块公式
![说明](图片地址)        → 图片（默认最大高 170px）
![说明](地址 =300x200)   → 图片（指定宽高）
```

### 链接

```
[文字](https://...)     → 外链（新标签页打开）
https://www.example.com → 裸 URL（自动转链接）
```

### 笔记跳转

```
[[目标笔记名]]                → 跳转到另一篇笔记
[自定义文字](note:目标笔记名) → 跳转（可改显示文字）
```

### 标签

```
#标签名                  → 添加标签（侧栏底部可见，点击可筛选）
#高频 #难题              → 一个节点多个标签
```

**解析优先级**：图片 > 笔记跳转 > 链接 > 裸 URL > LaTeX > 标签

## 二、文件夹分类

### 组织方式

侧栏按文件夹分组，树形结构：

```
📁 线性代数
  └─ 行列式
  └─ 矩阵
  └─ 向量组
📁 概率论
  └─ 随机变量
  └─ 数字特征
📥 未分类
  └─ 临时笔记
```

### 操作

| 操作 | 方式 |
|---|---|
| 新建笔记时指定文件夹 | 弹出提示框，输入或选择文件夹名 |
| 导入笔记时指定文件夹 | 同上 |
| 移动笔记 | 笔记右侧 📁 按钮，选择文件夹编号或新建 |
| 删除文件夹 | 文件夹标题右侧 × 按钮，笔记移到「未分类」 |
| 折叠/展开 | 点击文件夹标题 |
| 未分类 | 始终在最后，放未归档的笔记 |

### 兼容旧数据

没有 `folder` 字段的旧笔记自动归入「未分类」，不影响已有数据。

## 三、视图控制

### 工具栏按钮

```
⊕  全部展开     Ctrl+E
⊖  全部折叠     Ctrl+Shift+E
−  缩小         Ctrl+-
%  当前缩放     实时显示
+  放大         Ctrl++ 或 Ctrl+=
⤢  适配视图     Ctrl+0
```

### 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+E` | 全部展开 |
| `Ctrl+Shift+E` | 全部折叠 |
| `Ctrl+0` | 适配视图（自动缩放并居中） |
| `Ctrl+ +` / `Ctrl+ -` | 放大 / 缩小 |
| `Ctrl+F` | 聚焦选中节点 / 退出焦点 |
| `Esc` | 退出焦点模式 |
| `Ctrl+滚轮` | 鼠标缩放 |

### 焦点模式

导图太大找不到目标节点时：

1. 点选一个节点
2. 按 `Ctrl+F` 或点「聚焦」
3. 只显示该节点的子树，其他节点隐藏
4. 工具栏出现「焦点模式」橙色徽标
5. 按 `Esc` 或再点「聚焦」退出

### 适配视图

导图太大时按 `Ctrl+0`，自动：
- 计算所有节点包围盒
- 缩放到刚好放进屏幕
- 居中显示

## 四、标签系统

### 用法

在节点文本里写 `#标签名`，侧栏底部自动聚合：

```
#行列式 化简技巧        → 标签「行列式」
#高频 三步法            → 标签「高频」
#矩阵 基本运算 #高频    → 标签「矩阵」「高频」
```

### 操作

- 侧栏底部显示所有标签（绿色胶囊）
- 点击标签 → 打开第一篇含该标签的笔记
- 再次点击 → 取消筛选
- 标签来自所有笔记的节点文本，实时提取

### 与文件夹的区别

| | 文件夹 | 标签 |
|---|---|---|
| 归属 | 一个笔记只能在一个文件夹 | 一个笔记可以有多个标签 |
| 用途 | 主结构（科目/章节） | 次级筛选（频率/难度/类型） |
| 管理 | 侧栏树形 | 侧栏底部云 |

## 六、数据架构

```
localStorage:
  mm_notes_list        → 笔记索引 [{id, name, folder, created}]
  mm_notes:<id>        → 单篇笔记完整数据 {nodeData, arrows, summaries, direction, theme}
  mm_notes_sync_config → 云同步凭证 {keyId, accessKey, binId}
  mm_notes_last_sync   → 上次同步时间
```

**关键不变式**：`nodeData` 里每个节点的 `topic` 字段永远是原始纯文本（含 `$...$`、`[[x]]`、`![...](...)`、`#标签` 语法），`dangerouslySetInnerHTML` 是派生的视图层。每次加载都从 `topic` 重新生成 HTML（`applyInlineHtml`），保证编辑→保存→重新打开不丢失公式/链接/图片/标签。

## 七、技术实现

### 与 MindElixir 的关系

库一行没改。所有扩展通过公开 API 实现：

- `getData()` — 数据导出
- `bus.addListener("operation", cb)` — 编辑事件（自动保存）
- 节点的 `dangerouslySetInnerHTML` — 富文本渲染
- `refresh()` — 图片加载后重算布局

部署时唯一改动：ESM → 全局脚本（支持 `file://` 本地打开）。

### 文件结构

```
docs/public/notes/
├── index.html                  # 主页面（解析器 + UI + 同步）
├── README.md                   # 本文档
└── vendor/
    ├── mind-elixir.global.js   # 思维导图引擎（官方构建，未修改）
    └── katex/
        ├── katex.min.js        # LaTeX 渲染
        ├── katex.min.css
        └── fonts/*.woff2       # 20 个字体文件
```

## 九、技术备注

### MindElixir 对外 API（22 个）

```
init / refresh / getData / getDataString / getDataMd
expandNode / focusNode / toCenter / selectNode / selectNodes
unselectNode / unselectNodes / clearSelection / cancelFocus
enableEdit / disableEdit / scale / initLeft / initRight / initSide
setLocale / install
```

### 视图控制实现

- **全部展开/折叠**：递归修改 `nodeData` 的 `expanded` 字段，调 `mind.refresh()`
- **缩放**：用库的 `scale(v)` API，监听 `bus.fire('scale')` 更新标签
- **适配视图**：测量所有 `me-node` 包围盒 → 计算目标缩放 → `mind.scale(v)` → 滚动居中
- **焦点模式**：用库的 `focusNode(nodeObj)` / `cancelFocus()`，监听 `isFocusMode` 显示徽标
- **快捷键**：全局 `keydown` 监听，检查 `Ctrl+key` 组合，输入框内不触发

### 已知限制

1. **官方 `getDataMd()` 丢公式和链接** — 用自己的 `nodeDataToMd()` 替代，保留原始 topic
2. **千节点以上渲染慢** — 建议单篇笔记控制在 200 节点以内
3. **图片必须用外链 URL** — 不支持本地文件上传（需要后端图床）
4. **KaTeX 字体 1.2MB** — 首次加载慢，浏览器缓存后不慢

### 踩过的坑

1. `topic` 用 `textContent` 渲染，不解析 HTML → 必须用 `dangerouslySetInnerHTML`
2. `getData()` 在节点带 `dangerouslySetInnerHTML` 时，topic 会变成 HTML 字符串 → 必须用 `applyInlineHtml` 从纯文本重新生成
3. MindElixir 是 ESM，`file://` 下 ESM 被 CORS 拦 → 转全局脚本 + IIFE
4. Cloudflare 缓存旧的 404 → 文件加版本号重命名
5. KaTeX 字体路径相对页面解析 → 用 `./vendor/katex/fonts/`
6. 图片异步加载导致节点宽度变化 → 监听 `load` 事件后调 `mind.refresh()`
