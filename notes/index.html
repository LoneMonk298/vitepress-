从 Markdown 导入

粘贴 AI 生成的 Markdown 大纲，自动转成思维导图。
第一个节点作为根，缩进自动识别。

支持：
• ## / ### / #### 层级
• - / * / + 列表
• 1. 有序列表
• [[空格]] 缩进嵌套
• [文字](https://...) 外链
• [[目标笔记名]] 跳到另一篇笔记
• [文字](note:目标笔记名) 同上（可改显示文字）
• ![说明](图片地址) 插入图片（可写 =300x200 指定尺寸）
或
支持 XMind 2024 及以前版本（content.json）。
图片全部内嵌显示（base64）；多画布 → 多篇笔记。

服务器同步

所有笔记数据同步到自有服务器，支持大文件（无 100KB 限制）。
适合多设备备份：手机、电脑、平板数据互通。

统计与复习进度

各笔记复习进度一目了然：已完成 表示演示模式看到最后一张；复习到 x/y 表示下次可继续。
