# 408数据结构-快速应试技巧

## 二叉树的构建与遍历

### 前置知识
- 前序遍历：根左右
- 中序遍历：左根右
- 后序遍历：左右根
- 层序遍历：从上到下，从左到右

### 适用场景
任给一个二叉树的前序或后续遍历序列和中序遍历序列，快速构建出该二叉树。
- 给定前序遍历序列和中序遍历序列，快速构建出该二叉树。
- 给定中序遍历序列和后序遍历序列，快速构建出该二叉树。
