# 笔记导图 /notes/ — 实现说明与路线图

> 考研复习用的 Markdown 思维导图笔记工具，基于 MindElixir，已部署在 `https://blog.lonemonk.xyz/notes/`
> 入口：数学考点取舍表 → 右上角「笔记导图」按钮

---

## 一、Markdown 语法速查

所有语法写在节点文本里，保存后保留原文，编辑后不丢失。

### 结构

```
## 标题节点              → 解析时第一个节点作根
- 列表项                → 普通子节点
  - 缩进嵌套            → 更深层级（自动兼容 2/4 空格）
```

### 内容增强

```
$(-1)^{i+j}$            → LaTeX 行内公式（KaTeX 渲染）
$$\begin{pmatrix}A&B\end{pmatrix}$$  → LaTeX 块公式
![说明](图片地址)        → 图片（默认最大高 170px）
![说明](地址 =300x200)   → 图片（指定宽高）
```

### 链接

```
[文字](https://...)     → 外链（新标签页打开）
https://www.example.com → 裸 URL（自动转链接）
```

### 笔记跳转

```
[[目标笔记名]]                → 跳转到另一篇笔记
[自定义文字](note:目标笔记名) → 跳转（可改显示文字）
```

### 标签

```
#标签名                  → 添加标签（侧栏底部可见，点击可筛选）
#高频 #难题              → 一个节点多个标签
```

**解析优先级**：图片 > 笔记跳转 > 链接 > 裸 URL > LaTeX > 标签

## 二、文件夹分类

### 组织方式

侧栏按文件夹分组，树形结构：

```
📁 线性代数
  └─ 行列式
  └─ 矩阵
  └─ 向量组
📁 概率论
  └─ 随机变量
  └─ 数字特征
📥 未分类
  └─ 临时笔记
```

### 操作

| 操作 | 方式 |
|---|---|
| 新建笔记时指定文件夹 | 弹出提示框，输入或选择文件夹名 |
| 导入笔记时指定文件夹 | 同上 |
| 移动笔记 | 笔记右侧 📁 按钮，选择文件夹编号或新建 |
| 删除文件夹 | 文件夹标题右侧 × 按钮，笔记移到「未分类」 |
| 折叠/展开 | 点击文件夹标题 |
| 未分类 | 始终在最后，放未归档的笔记 |

### 兼容旧数据

没有 `folder` 字段的旧笔记自动归入「未分类」，不影响已有数据。

## 三、视图控制

### 工具栏按钮

```
⊕  全部展开     Ctrl+E
⊖  全部折叠     Ctrl+Shift+E
−  缩小         Ctrl+-
%  当前缩放     实时显示
+  放大         Ctrl++ 或 Ctrl+=
⤢  适配视图     Ctrl+0
```

### 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+E` | 全部展开 |
| `Ctrl+Shift+E` | 全部折叠 |
| `Ctrl+0` | 适配视图（自动缩放并居中） |
| `Ctrl+ +` / `Ctrl+ -` | 放大 / 缩小 |
| `Ctrl+F` | 聚焦选中节点 / 退出焦点 |
| `Ctrl+Shift+F` | 打开侧栏全局搜索（搜所有笔记） |
| `Esc` | 退出焦点模式 |
| `Ctrl+滚轮` | 鼠标缩放 |

### 全局搜索（跨笔记）

笔记多了找不到节点时，在侧栏顶部的搜索框输入关键词（或按 `Ctrl+Shift+F`）：

- 实时搜索**所有笔记**的节点，按匹配度排序
- 每条结果显示：所属笔记名 + 节点文字 + 祖先路径
- 点击结果 → 自动打开对应笔记并定位、高亮该节点
- 匹配规则与笔记内搜索一致（支持模糊拆分，如输入"泰勒"命中"泰勒公式"）

### 双链反查（谁引用了我）

当前笔记被其他笔记引用时，点侧栏顶部的 `⇄` 按钮查看：

- 自动识别 `[[笔记名]]`、`[文字](note:笔记名)`、`(note:笔记名)` 三种引用写法
- 列出所有引用位置（笔记名 + 引用节点文字）
- 点击条目 → 跳转到引用所在的笔记与节点，反查窗口自动关闭

适合做跨笔记知识串联：在"概率论"笔记里用 `[[高数]]` 引用，随时反查谁在追这条线索。

### 焦点模式

导图太大找不到目标节点时：

1. 点选一个节点
2. 按 `Ctrl+F` 或点「聚焦」
3. 只显示该节点的子树，其他节点隐藏
4. 工具栏出现「焦点模式」橙色徽标
5. 按 `Esc` 或再点「聚焦」退出

### 适配视图

导图太大时按 `Ctrl+0`，自动：
- 计算所有节点包围盒
- 缩放到刚好放进屏幕
- 居中显示

### 演示模式（XMind 漫游式复习）

类 XMind 的「漫游」功能，把整篇导图变成逐张幻灯片放映，适合一天天滚动复习：

1. 点工具栏「演示」或按 `Ctrl+P` 进入
2. 选中节点后进入 → 从该节点开始；未选中 → 提示**继续上次复习位置**（按笔记分别记忆）
3. 每张幻灯片聚焦一个节点：当前节点琥珀色高亮，祖先路径与直接子节点为上下文，其余节点淡化
4. 翻页时平滑运镜（460ms 缓动缩放 + 平移），长公式链自动缩到完整可见
5. 到达最后一张视为本轮复习完成，进度自动重置，下次从头开始
6. 按 Esc 退出，恢复原来的展开状态和缩放

**底部控制条：**

```
✕  ⏮ ◀  1/438  ▶ ⏭  自动  1x▾
```

- `✕` 退出演示（Esc）
- `⏮` / `◀` / `▶` / `⏭` 第一张 / 上一张 / 下一张 / 最后一张
- `自动` 自动播放（默认每 4.2 秒一张）
- `1x▾` 播放速度：`0.5x / 1x / 1.5x / 2x`，选择后记住，下次打开仍生效

**快捷键：**

| 快捷键 | 功能 |
|---|---|
| `Ctrl+P` | 进入演示（选中节点则从该节点开始，否则续看上次进度） |
| `←` / `→` | 上一张 / 下一张 |
| `空格` | 下一张 |
| `Home` / `End` | 第一张 / 最后一张 |
| `Esc` | 退出演示 |

**进度记忆**：演示进度按笔记分别存入 `mm_present_pos`，退出时保存当前位置；看到最后一张自动标记「已完成」，下次进入不再续看、从头开始。

**适用场景**：
- 每天滚动复习：打开「演示」→ 继续上次位置 → 看完标记完成
- 复习时把思维导图当幻灯片讲
- 自己回忆时强制聚焦单一节点

## 四、标签系统

### 用法

在节点文本里写 `#标签名`，侧栏底部自动聚合：

```
#行列式 化简技巧        → 标签「行列式」
#高频 三步法            → 标签「高频」
#矩阵 基本运算 #高频    → 标签「矩阵」「高频」
```

### 操作

- 侧栏底部显示所有标签（绿色胶囊）
- 点击标签 → 打开第一篇含该标签的笔记
- 再次点击 → 取消筛选
- 标签来自所有笔记的节点文本，实时提取

### 与文件夹的区别

| | 文件夹 | 标签 |
|---|---|---|
| 归属 | 一个笔记只能在一个文件夹 | 一个笔记可以有多个标签 |
| 用途 | 主结构（科目/章节） | 次级筛选（频率/难度/类型） |
| 管理 | 侧栏树形 | 侧栏底部云 |

### XMind 文件导入

点「导入」→「📦 导入 .xmind 文件」选择 .xmind（本质是 ZIP 包），全程本地解析、无需联网：

| XMind 内容 | 导入结果 |

## 六、数据架构

```
localStorage:
  mm_notes_list        → 笔记索引 [{id, name, folder, created, updated}]
  mm_notes_sync_config → 云同步凭证 {keyId, accessKey, binId}
  mm_notes_last_sync   → 上次同步时间
  mm_present_pos       → 演示复习进度 {<noteId>: {idx, total, completed, t}}
  mm_present_speed     → 自动播放速度（0.5 / 1 / 1.5 / 2）
  mm_notes_sort        → 侧栏排序方式（default / name / edited / created）

IndexedDB（mm-notes-db / notes，keyPath=id）:
  mm_notes:<id>        → 单篇笔记完整数据 {nodeData, arrows, summaries, direction, theme}
                         （含图片 base64 时可达数 MB~十几 MB，localStorage 5MB 装不下，
                         因此笔记正文存 IndexedDB，配额为 GB 级；旧 localStorage 数据首次
                         打开自动迁移，不支持 IndexedDB 的浏览器回退 localStorage 存储）
```

**关键不变式**：`nodeData` 里每个节点的 `topic` 字段永远是原始纯文本（含 `$...$`、`[[x]]`、`![...](...)`、`#标签` 语法），`dangerouslySetInnerHTML` 是派生的视图层。每次加载都从 `topic` 重新生成 HTML（`applyInlineHtml`），保证编辑→保存→重新打开不丢失公式/链接/图片/标签。

## 九、技术备注

### MindElixir 对外 API（22 个）

```
init / refresh / getData / getDataString / getDataMd
expandNode / focusNode / toCenter / selectNode / selectNodes
unselectNode / unselectNodes / clearSelection / cancelFocus
enableEdit / disableEdit / scale / initLeft / initRight / initSide
setLocale / install
```

### 视图控制实现

- **全部展开/折叠**：递归修改 `nodeData` 的 `expanded` 字段，调 `mind.refresh()`
- **缩放**：用库的 `scale(v)` API，监听 `bus.fire('scale')` 更新标签
- **适配视图**：测量所有 `me-node` 包围盒 → 计算目标缩放 → `mind.scale(v)` → 滚动居中
- **焦点模式**：用库的 `focusNode(nodeObj)` / `cancelFocus()`，监听 `isFocusMode` 显示徽标
- **快捷键**：全局 `keydown` 监听，检查 `Ctrl+key` 组合，输入框内不触发
- **演示模式**：先序遍历收集所有节点 → 每张幻灯片备份整树 → 全部折叠 → 只展开到当前节点路径 → 用 `Range` 测真实内容包围盒（KaTeX 溢出 35em 盒子的部分也计入）→ 目标缩放可低至 0.2 → `requestAnimationFrame` 缓动运镜 → 类名高亮/淡化上下文节点 → 进度写入 `mm_present_pos`

### 已知限制

1. **官方 `getDataMd()` 丢公式和链接** — 用自己的 `nodeDataToMd()` 替代，保留原始 topic
2. **千节点以上渲染慢** — 建议单篇笔记控制在 200 节点以内
3. **图片必须用外链 URL** — 不支持本地文件上传（需要后端图床）
4. **KaTeX 字体 1.2MB** — 首次加载慢，浏览器缓存后不慢

### 踩过的坑

1. `topic` 用 `textContent` 渲染，不解析 HTML → 必须用 `dangerouslySetInnerHTML`
2. `getData()` 在节点带 `dangerouslySetInnerHTML` 时，topic 会变成 HTML 字符串 → 必须用 `applyInlineHtml` 从纯文本重新生成
3. MindElixir 是 ESM，`file://` 下 ESM 被 CORS 拦 → 转全局脚本 + IIFE
4. Cloudflare 缓存旧的 404 → 文件加版本号重命名
5. KaTeX 字体路径相对页面解析 → 用 `./vendor/katex/fonts/`
6. 图片异步加载导致节点宽度变化 → 监听 `load` 事件后调 `mind.refresh()`
7. 长公式链不可换行、溢出 35em 节点盒子 → 演示取景用 `Range` 测真实包围盒，缩放下限从 0.5 放宽到 0.2
8. 单击节点只设置 `currentNode`（多选才是 `currentNodes`）→ 演示入口同时兼容两者
9. `focusNode()` 聚焦时 `getData()` 返回整树备份、不返回子树 → 演示不再依赖聚焦，直接用完整树 + 折叠/展开控制路径

### 2026-10-14 · 图片交互与选中修复（v2）
- **修复图片无法点击查看**：根因是 MindElixir 官方 CSS 给 `me-wrapper` 设了 `pointer-events:none`（画布空白穿透），而 pointer-events 是继承属性，节点内图片也继承了 none——真实点击永远落不到 img 上，单击放大拦截器收不到事件。已给 `#map img` 显式恢复 `pointer-events:auto`，真实点击图片即弹放大预览、且不选中节点
- **修复文字节点无法选中/编辑**：根因是图片 load 触发布局刷新（`mind.refresh()`）形成「load → refresh → 重建 DOM → 图片重新 load」无限循环，每次重建都会清掉节点选中态（单击选中后 ~150ms 即消失，看起来像"选不中"）。修复：①img 的 load/error 委托按 **src 去重**，同一张图只触发一次布局刷新，循环根治；②`scheduleLayoutRefresh` 在 refresh 前记录当前选中节点 id、刷新后按 id 恢复选中，任何刷新都不再丢选中
- 验证：文字节点单击选中持续保持、双击进入编辑、点击图片放大且不选中节点、演示模式内看图不翻页、Esc 先关图再退演示

### 2026-10-14 · 图片交互修复
