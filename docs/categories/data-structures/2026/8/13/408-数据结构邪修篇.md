# 408数据结构-快速应试技巧

## 二叉树的构建与遍历

### 前置知识
- 前序遍历：根左右
- 中序遍历：左根右
- 后序遍历：左右根
- 层序遍历：从上到下，从左到右

### 适用场景
- 给定前序遍历序列和中序遍历序列，快速构建出该二叉树。
- 给定中序遍历序列和后序遍历序列，快速构建出该二叉树。

## m阶B树的插入与删除

### 前置知识
对于m阶B树，有以下性质：
- 根节点：至少有1个关键字；至多有$m-1$个关键字。
- 非根节点：至少有$\lceil m/2 \rceil-1$个关键字；至多有$m-1$个关键字。
- 子树数：关键字数+1。

### 适用场景
- 给定序列插入关键字到m阶B树中/空树。
- 从m阶B树中删除关键字。
